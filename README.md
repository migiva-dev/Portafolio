# Portfolio — Miguel Gavila

Portfolio personal, blog y CV desarrollado con tecnologías web nativas. Desplegado y optimizado para **GitHub Pages**.

## 🌐 Demo en Vivo
Puedes visitar el proyecto funcionando aquí:  
👉 **[https://migiva-dev.github.io/Portafolio/](https://github.com/migiva-dev/Portafolio)**

---

## 🛠️ Stack
* **Frontend:** HTML5 (Semántico), CSS3 (Flexbox, Grid, Custom Properties).
* **Assets:** Optimización de imágenes para web (PNG/JPG).
* **Despliegue:** GitHub Pages.

---

## 📂 Estructura del proyecto

```text
Portfolio/
├── IMG-PORT/           # Directorio de recursos visuales y proyectos
├── index.html          # Home — Presentación y Hero
├── portfolio.html      # Galería de proyectos y trabajos
├── blog.html           # Listado de artículos y notas técnicas
├── cv.html             # Currículum Vitae interactivo
├── contacto.html       # Formulario y enlaces de contacto
├── style.css           # Hoja de estilos global y responsive
├── img-inicio.png      # Imagen principal de cabecera
└── img_cv.png          # Imagen específica para la sección CV

```
