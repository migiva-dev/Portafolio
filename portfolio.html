Gant Task Manager

Desarrollo de una aplicación web interactiva basada en una tabla de Gantt para la gestión y organización de tareas por semanas.

La interfaz está diseñada para ser intuitiva y eficiente, mejorando la experiencia de usuario en la gestión del tiempo y la productividad.
